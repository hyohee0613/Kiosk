# 키오스크 (필수 LV 5)

콘솔 환경에서 동작하는 키오스크 프로그램 입니다.
사용자는 카테고리별 메뉴를 선택하고, 그 메뉴의 개별 항목을 확인한 뒤 선택할 수 있습니다.

- 기능
    - 메인 메뉴(카테고리) 출력
    - 카테고리 선택 시 개별 메뉴 출력
    - 뒤로가기 및 프로그램 종료 기능


- 사용 방법
    1. 실행
    2. 카테고리 메뉴 선택
    3. 개별 메뉴 선택


- 클래스 구성
    - Main: 메뉴 구성 및 출력, 키오스크 실행
    - MenuItem: 메뉴 항목 정보 (이름, 가격, 설명)
    - Menu: 카테고리 이름 및 MenuItem 리스트 관리
    - Kiosk: 사용자 입력 처리 및 메뉴 흐름 제어
